Does the mobile application function offline?

Yes. The road network graph and active dispatch instructions cache locally, syncing automatically when cellular connectivity restores.

What Android permissions are required?

High-accuracy GPS location for responder tracking, push notifications for critical triage dispatches, and storage for the spatial map cache.

How is the release APK deployed to field units?

The 55 MB standalone package installs directly on municipal mobile devices without third-party app store dependencies.
